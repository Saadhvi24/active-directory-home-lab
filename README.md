# Active Directory Home Lab

## Overview

A hands-on Active Directory home lab built using Windows Server 2022 and Windows 11 to practice enterprise IT administration and cybersecurity concepts.

## Lab Environment

- Windows Server 2022
- Windows 11 Client
- Oracle VirtualBox
- Active Directory Domain Services (AD DS)
- DNS
- Domain: `savitech.local`

## What I Practiced

- Installed and configured Windows Server
- Installed Active Directory Domain Services
- Created the `savitech.local` domain
- Created Organizational Units (OUs)
- Created and managed domain users
- Created security groups
- Added users to security groups
- Joined a Windows 11 PC to the domain
- Configured shared folders
- Configured NTFS and share permissions
- Tested access using domain accounts
- Verified domain connectivity and authentication

## Skills Demonstrated

- Active Directory Administration
- Windows Server Administration
- User and Group Management
- Organizational Units (OUs)
- Domain Administration
- DNS Fundamentals
- File Sharing
- NTFS Permissions
- Share Permissions
- Troubleshooting
